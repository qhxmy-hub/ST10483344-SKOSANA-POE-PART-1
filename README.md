# Themba Givers Website

## Project Description

Themba Givers is a non-profit organisation website created as part
of the WEDE5020 Web Development Introduction module.

The website provides information about the organisation, its services,
ways that people can help, and how community members can contact the
organisation.

## Website Pages

The website contains five main pages:

1. Home
2. About
3. Services
4. Enquiries
5. Contact Us

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Web browser for testing

## CSS Features

The website uses an external CSS stylesheet.

The CSS includes:

- Typography
- Colours
- Navigation styling
- Buttons
- Cards
- Forms
- Image styling
- Hover effects
- Focus effects
- Responsive design
- Media queries

## Responsive Design

The website was designed to work on desktop, tablet and mobile
screen sizes.

Media queries were used at:

- 768px
- 480px

## Colour Scheme

The website uses warm and welcoming colours:

- Orange header
- Dark green navigation
- Gold highlights
- Cream background
- White content cards
- Orange buttons
- Green footer

These colours were selected to create a friendly and welcoming
appearance suitable for a non-profit organisation.
